# Rail Samanvay — AI-Powered Railway Block Planning

> **Smart India Hackathon · Team SPIDER CODES · Problem Statement ID: 178452**

Rail Samanvay is an intelligent corridor block planning and optimization system designed for Indian Railways. It merges disparate departmental maintenance requests (Engg, S&T, TRD) into synchronized, conflict-free, human-approved maintenance blocks—maximizing asset availability while keeping trains on schedule.

---

## 🚀 Key Highlights

- **Intelligent Block Aggregation:** Algorithmic coordination of departmental maintenance requirements.
- **Cinematic Web Interface:** State-of-the-art dark theme, glassmorphic UI, dynamic micro-interactions, responsive design.
- **Integrated Visual Identity:** Custom brand logo and high-resolution network topology background.
- **Interactive Simulator:** Real-time demonstration showing fragmented maintenance requests merging into unified corridor blocks.

---

## 🛠 Tech Stack

- **Frontend:** Pure semantic HTML5, Vanilla CSS3 with hardware-accelerated animations, and Vanilla JavaScript.
- **Design Tokens:** Dark navy `#070e18`, Railway Amber `#f2a93b`, Steel Blue `#7aa2c7`, and glassmorphic depth layers.
- **Zero External Runtime Dependencies:** Runs immediately in any modern browser without build steps.
